# Dual build kept test component implicit unit test dependency

- **Learned from:** inner loop friction on CL I7aea904d7b1480880c8812bc19eeafa12b95d500, patchset 1 (task `pkg-cache-config`)
- **Date:** 2026-10-20
- **Changed:** `checks/migration_sanity.sh`

## Root cause

In checks/migration_sanity.sh, check_unmigrated_kept_pkg_test_targets and
inspect_gn_target_deps checked whether a kept GN test component's local
dependencies existed in pre_targets or had GN-only blockers, but did not exclude
test components whose local dependency is an implicit <owner>_test unit-test
target generated by an unmigrated with_unit_tests = true target or a non-test
binary kept above the BAZEL2GN SENTINEL that is absent from BUILD.bazel.

## Why not a one-off fix

Exempting a single package directory would leave
check_unmigrated_kept_pkg_test_targets falsely flagging any other dual-build
package where a kept fuchsia_component or fuchsia_test_component above the
BAZEL2GN SENTINEL packages an implicit <owner>_test binary from an unmigrated
rustc_binary or rustc_library with with_unit_tests = true.
